# Goal

[English](GOAL.md) / [한국어](GOAL-ko.md)

Create a personal image library for jyje's own projects. Make images as actual needs arise, keep each reusable file with the decisions behind it, and make it easy to link to the file or adapt the recipe later.

| Area | Initial scope |
| --- | --- |
| Use cases | Start with product empty states and document or presentation banners |
| Palette | Use the shared red-bean accent `#680C2C` from both profile projects and choose backgrounds and supporting colors by use |
| Style | Record shape, depth, texture, composition, and treatments to avoid |
| Recipe | Connect a use case, palette, style, output size, and composition |
| Gallery | Separate approved assets and comparison samples. Link each image to its file and recipe |
| Reuse | Use a direct file link or copy the approved asset into the project that uses it. Track the asset or recipe ID in the consuming project |
| Starter setup | Adapt the goal, plan, README, docs, CI, and PR structure from `template-pilot-ai-python`. Use Node.js built-ins for validation |

## First pilot success criteria

1. Create and approve an image for a real screen, document, or presentation. Check color and composition in that placement.
2. In a later task, find the image by use case and reuse the file or adapt the recipe for the new subject. Record where it was used.
3. Trace the approved asset to its palette, style, recipe, source, and reuse terms.
