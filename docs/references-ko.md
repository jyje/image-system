# 공개 디자인 시스템 사례

[English](references.md) / [한국어](references-ko.md)

| 사례 | 운영 방식 | 이 프로젝트에 반영할 점 |
| --- | --- | --- |
| Lobe Icons | 검색 가능한 시각 카탈로그를 제공하고, 아이콘 식별자로 정적 SVG를 직접 참조할 수 있게 합니다. [카탈로그](https://icons.lobehub.com/), [정적 SVG 사용법](https://github.com/lobehub/lobe-icons/tree/master/packages/static-svg) | 파일 옆에 미리보기를 두고 자산 ID를 유지해 다른 프로젝트에서 이미지를 찾고 바로 참조할 수 있게 합니다. |
| Atlassian Design | 제품에서 단일 개념을 설명하는 스팟 삽화, 흐름을 설명하는 간략한 UI, 배경 패턴을 구분합니다. 빈 상태와 오류 같은 맥락에는 스팟을 권장하고 기존 라이브러리 자산의 활용을 안내합니다. [Illustrations](https://atlassian.design/guidelines/brand/illustrations/) | 용도를 갤러리의 첫 분류로 삼고 새로 만들기 전에 기존 자산을 찾습니다. |
| Atlassian Design Color | UI 색상 토큰에 적용 대상, 역할, 강조 수준을 표현합니다. [Color](https://atlassian.design/foundations/color) | 이 원칙을 이미지 팔레트에 적용해 HEX 값마다 배경, 강조, 중립처럼 역할을 붙입니다. |
| IBM Design Language | 선, 평면, 아이소메트릭 삽화를 각각 별도의 키트로 제공합니다. [Resources](https://www.ibm.com/design/language/resources/) | 스타일마다 대표 샘플과 형태·깊이·질감 규칙을 함께 둡니다. |
| Adobe Spectrum | 선형과 그라디언트 삽화를 화면에서 필요한 주목도에 따라 구분합니다. 강한 주목도를 가진 그라디언트 삽화는 제한적으로 사용합니다. [Illustration](https://spectrum.adobe.com/foundations/visual-language/illustration) | 같은 스타일이라도 사용처와 시각적 강조 수준을 명시합니다. |
| Adobe Firefly | 스타일 참조와 구조 참조를 별도로 조절할 수 있고, 참조의 영향 강도를 지정할 수 있습니다. [Style Image Reference](https://developer.adobe.com/firefly-services/docs/firefly-api/guides/concepts/style-image-reference/), [Structure Image Reference](https://developer.adobe.com/firefly-services/docs/firefly-api/guides/concepts/structure-image-reference/) | 생성 도구를 비교할 때 분위기와 구도를 독립 조건으로 기록합니다. |
